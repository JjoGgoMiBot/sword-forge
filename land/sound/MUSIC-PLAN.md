# 장소별 음악: 편안한 마을과 여백

사용자가 선택한 방향은 스타듀밸리나 마인크래프트 BGM처럼 편안하고 여백 있는 음악이다. 이전의 관악기 주선율·오케스트라 편성·규칙적인 반주를 이어가지 않고, 피아노와 기타를 중심으로 다시 작곡했다. 원작의 선율이나 녹음은 사용하지 않는다.

| 장소 | 편성과 역할 | 속도 · 길이 |
|---|---|---|
| 메인 광장 | 실제 업라이트 피아노와 클래식 기타. 따뜻한 마을, 선율 사이의 쉼 | 78 BPM · 약 98초 |
| 오락관 | 작은 피아노와 기타. 드문 베이스와 아주 약한 브러시로만 장소 차이 | 86 BPM · 약 89초 |
| 대장간 | 기타 핑거피킹과 낮은 피아노. 행진곡 대신 편안한 작업 공간 | 82 BPM · 약 94초 |
| 타로관 | 드문 피아노 음, 긴 여운, 옅은 배경 텍스처. 지속적인 아르페지오 없음 | 64 BPM · 120초 |

32마디에 조용한 도입, 주제, 선율 변화, 귀환을 둔다. 첫 4마디는 도입, 마지막 4마디는 주선율을 쉬는 구간이다. 8마디 끝마다 선율을 쉬고, 실제 음표 사이에도 쉼을 둔다. 고정된 박자마다 모든 악기를 채우지 않는다. MIDI 타이밍에는 반복 가능한 작은 차이를 주고, 강약과 음 길이도 다르게 한다.

피아노는 FreePats Upright Piano KW, 기타는 FreePats Spanish Classical Guitar의 원래 SFZ 녹음을 sfizz로 렌더했다. 예전 범용 GM 리드 악기를 재사용하지 않는다. GeneralUser GS는 아주 조용한 배경 소리와 오락관의 약한 브러시에만 남긴다. 출처·라이선스·해시·렌더 명령은 `land/assets/music/CREDITS.md`에 기록했다.

세 번 연속 렌더한 가운데 사이클을 사용한다. 음량은 측정한 뒤 고정 게인으로만 맞춰 조용한 구간을 강제로 키우지 않는다. 저역통과 필터와 강한 압축을 적용하지 않는다. 첫 입력 후 재생, 장소별 자동 전환, 다음 곡 준비 후 크로스페이드, 음량 설정과 효과음 덕킹은 유지한다. 파일 실패 시 이전 음악을 유지하고, 거절된 합성 음악으로 바꾸지 않는다.

재생·파일·출력 검증은 예술적 완성도의 판정과 구분한다. 미리듣기는 서비스와 동일한 파일이다.
